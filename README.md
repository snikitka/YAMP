**Плеер для Яндекс Музыки. На компьютере и на телефоне.**

Включите Мою волну или любимый плейлист и слушайте в **FLAC без потерь** до
24 бит / 192 кГц. Без рекламы, без лишнего, в лёгком и быстром приложении.

> Для подписчиков **Яндекс Плюс**.

## Слушать

**Моя волна.** Нажмите «Играть», и музыка пойдёт сама, подобранная под ваш
вкус. Лайк запоминает трек, дизлайк сразу его пропускает, и волна
подстраивается под вас прямо на ходу.

**Волна по чему угодно.** Запустите волну по треку, альбому, плейлисту или
исполнителю и слушайте похожую музыку. А когда альбом или плейлист
закончится, YAMP сам продолжит волной по последнему треку, чтобы тишина не
наступала.

**Вся ваша музыка.** «Мне нравится», ваши плейлисты и сохранённые, история
прослушиваний, чарт и новые релизы. Всё на главной, в пару нажатий.

**Поиск на лету.** Начните вводить название песни, альбома или имя
исполнителя, и результаты появятся сразу. Опечатки не страшны.

**Очередь под контролем.** Смотрите, что заиграет дальше, перескакивайте на
любой трек, перемешивайте, повторяйте один трек или весь плейлист по кругу.

**Плавные переходы.** Конец трека мягко затихает, а следующий в это время
набирает громкость, без резких обрывов и пауз. Длительность от 1 до 12 секунд,
а если не нравится, переходы выключаются в настройках. Альбомы играют встык,
как задумал исполнитель.

**Звук как в студии.** Настоящий lossless, а не пережатая копия. Если у трека
нет версии без потерь, YAMP возьмёт лучшее из доступного. Для мобильного
интернета есть MP3 и экономный режим.

**Играет в фоне.** На телефоне плеер живёт в уведомлении и на экране
блокировки: там же можно поставить лайк или дизлайк. Кнопки наушников тоже
работают. На компьютере музыка не прерывается, даже когда окно свёрнуто.

**Не боится плохой связи.** Пропал Wi-Fi или телефон переключился на мобильный
интернет? YAMP дождётся сети и продолжит с того же места, ничего не придётся
включать заново.

**Делитесь настроением.** Друзья в Discord увидят, что вы сейчас слушаете.

**Телефон вместо пульта.** Наведите камеру телефона на QR-код в настройках
YAMP на компьютере, и музыкой можно управлять с дивана: пауза, перемотка,
громкость, лайки, следующий трек. Всё идёт напрямую по домашней сети в
зашифрованном виде, а компьютер слушается только связанные с ним телефоны.

## А ещё

**Скачать, чтобы было всегда.** Треки, альбомы, плейлисты и целые дискографии
в FLAC или MP3 320, с обложками и названиями, аккуратно разложенные по
папкам. Можно отметить только нужные треки или альбомы, а можно просто
вставить ссылку из Яндекс Музыки.

**Приятно пользоваться.** Современный интерфейс, тёмная и светлая темы.

**Всегда свежая версия.** YAMP сам замечает обновления и ставит их в пару
нажатий.

## Вход за минуту

Нажмите «Войти через Яндекс», откройте [ya.ru/device](https://ya.ru/device) на
любом устройстве и введите код из приложения. Всё, пароль никуда вводить не
нужно, а заходить заново не придётся.

## Ваши данные остаются вашими

Доступ к аккаунту хранится только на вашем устройстве и нигде больше. YAMP
общается напрямую с Яндексом, без посредников и сбора статистики. При выходе
из аккаунта доступ закрывается и на стороне Яндекса. Код программы открыт:
каждый может проверить, что она делает.

## Скачать

Свежая версия всегда на странице [релизов](../../releases):

| Где | Что скачать |
|---|---|
| Android | `YAMP-android-arm64.apk` |
| Windows | `YAMP-windows.zip` |
| macOS | `YAMP-macos.dmg` |
| Linux | `YAMP-linux-x86_64.AppImage` |

На Android откройте файл и разрешите установку. Для старых 32-битных телефонов
есть `YAMP-android-arm.apk`.

На macOS при первом запуске система может заблокировать приложение. Откройте
«Системные настройки», раздел «Конфиденциальность и безопасность», и нажмите
«Всё равно открыть».

На Linux для прослушивания нужна библиотека libmpv из репозитория дистрибутива.
Без неё работает только загрузка.

```sh
sudo apt install libmpv2      # Debian 12+, Ubuntu 24.04+
sudo apt install libmpv1      # Ubuntu 22.04
sudo dnf install mpv-libs     # Fedora
sudo pacman -S mpv            # Arch
```
